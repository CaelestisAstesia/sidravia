# 快速开始

本文面向使用吉林大学 Dr.Com 5.2.0 D 认证的 Windows 用户，从安装到完成第一次 GUI 连接。只需要命令行时，阅读[高级使用](advance.md)。

## 1. 选择发行包

在 [Releases](https://github.com/CaelestisAstesia/sidravia/releases) 查看实际下载文件与发行说明。当前开发线为 `0.3.0-alpha.1`；支持范围与已知问题以对应版本说明为准。

| 文件 | 用途 |
| --- | --- |
| `sidravia-v<版本>-windows-amd64-setup.exe` | 使用安装器、快捷方式和 Windows 卸载入口 |
| `sidravia-v<版本>-windows-amd64-portable.zip` | 解压运行，将认证配置和日志保存在程序目录 |
| `SHA256SUMS.txt` | 核对下载文件的 SHA256 |

选择包含图形界面的包或安装组件。完整 GUI 包包含 `Sidravia.exe`、`sidraviactl.exe`、`sidraviad.exe`、`sidraviamgr.exe` 和配套文件；仅含核心的包不能打开 GUI。不要单独复制某个 EXE 运行。

如需核对下载文件，在 PowerShell 中替换为实际文件名：

```powershell
Get-FileHash .\sidravia-v0.3.0-alpha.1-windows-amd64-portable.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

将完整哈希与清单中对应文件的值比较。

## 2. 安装或解压

**安装版**：运行安装器，选择安装目录和图形界面组件。快捷方式、登录自启和 PATH 按需选择；日常 GUI 使用选择启动到托盘的自启方式。

**便携版**：完整解压到固定、当前用户可写的目录，运行 `Sidravia.exe`。不要在 ZIP 中直接运行，也不要删除包里的 `sidravia.portable` 标记。认证配置、日志和 GUI 设置保存在程序目录，学校公告网页缓存仍在用户目录。

先退出其他认证客户端；如果它们会随 Windows 自动启动，也应关闭相应自启设置，避免同时认证。安装版与便携版不自动迁移彼此的数据；也不要将安装版覆盖到便携目录。具体位置见[数据与隐私](privacy.md)。

## 3. 保存账号并连接

1. 接入需要认证的网络，打开 Sidravia。
2. 进入「设置 → 连接配置」，选择机构，填写账号与密码。
3. 网卡先使用自动选择；有多块网卡时，可指定认证网络对应的网卡与 IPv4。
4. 点击「保存修改」，在确认框选择「保存并连接」。也可先保存，再回首页连接。
5. 等待首页显示认证成功，再实际打开网页确认网络可用。

认证成功与互联网可用是两个结果。遇到失败先记录界面提示，按[常见问题](troubleshooting.md)排查。

密码会以明文保存在本地文件，并依赖系统文件权限保护。出现存储保护提示时，先了解[账号与密码的保存方式](privacy.md#账号与密码)，再决定是否继续。

## 4. 按需设置自动连接

首次手动连接成功后，再设置：

- 「启动时自动登录」：后台启动后，按已保存配置尝试认证。
- 「自动重连」：连接遇到可恢复的故障时重试。
- 「开机自启」：当前用户登录 Windows 时启动程序。

三者分别控制不同的行为，详见[自动连接与开机自启](guide.md#自动连接与开机自启)。

默认关闭窗口会隐藏到托盘，连接继续保持。需要结束连接并退出时，在托盘菜单选择「退出 Sidravia」。其余操作见[使用指南](guide.md)。
