# 数据与隐私

本文说明当前版本保存的数据、网络通信和诊断边界。使用方法见[快速开始](quick-start.md)，高级操作见[高级使用](advance.md)。

## 账号与密码

认证账号、密码和连接设置保存在本地 `configurations.json`，供后续连接和自动登录使用。**密码是明文，当前没有使用密码加密或系统凭据保险库。**

Windows 使用文件访问权限限制当前用户与 LocalSystem 访问，Linux 使用用户私有文件权限。权限保护不等于加密，不能阻止已获得当前用户权限的程序或更高权限的系统访问。

保护无法建立时，程序要求明确确认后才允许相应保存操作。确认仅表示接受当前存储条件，不会加密密码或修复文件权限。备份、同步和复制配置文件会产生额外的敏感副本，请按密码文件保管。

ctl 的交互密码输入不回显；脚本可通过 `--password-stdin` 输入。不要将密码直接写在命令行、终端历史或公开脚本中。

## 数据位置

常规 Windows 布局如下，不含开发或测试命名空间：

| 数据 | 安装版 | 便携版 |
| --- | --- | --- |
| 账号与认证配置 | `%APPDATA%\Sidravia\configurations.json` | `<程序目录>\config\configurations.json` |
| GUI 偏好 | `%APPDATA%\Sidravia\gui-settings.json` | `<程序目录>\config\gui-settings.json` |
| 后台运行信息 | `%LOCALAPPDATA%\Sidravia\runtime.json` | `<程序目录>\runtime\runtime.json` |
| 后台日志 | `%LOCALAPPDATA%\Sidravia\logs\` | `<程序目录>\logs\` |

程序目录的 `institution-profiles` 保存随版本提供的机构配置，不含用户密码。GUI 偏好保存外观、通知和窗口等设置，不保存认证密码。

程序目录中的普通文件 `sidravia.portable` 启用便携布局。添加或删除标记只改变后续使用的数据位置，不会迁移已有数据。Linux 便携包也将配置、运行信息与日志保存在程序目录。

学校公告是便携布局的例外：Windows WebView2 缓存和网页数据位于 `%LOCALAPPDATA%\Sidravia\announcement-webview\production\`，安装版和便携版均如此。当前卸载的数据删除流程不清理此目录，删除便携目录也不会移除它。

## 网络通信

认证核心按照所选协议与认证服务器通信。当前 D520 使用账号及协议要求的认证、主机和网络信息；本地文件权限保护不表示协议传输经过加密。

GUI 与后台通过本机回环 WebSocket 交换命令和状态。学校公告窗口另行加载机构配置指定的网页，学校网站会接收普通网页请求；网站的数据处理由其自身决定。当前吉林大学公告入口使用 HTTP，没有 HTTPS 传输保护。

## 日志与诊断

普通日志和诊断用于解释状态与失败原因。TRACE 记录完整协议数据报，可能含账号和认证信息；按排障需要开启，完成后恢复原等级，并重启核心使等级生效。

GUI 的诊断复制和 ctl 的 `diagnostics export` 使用限定字段的摘要，避免直接输出密码与原始报文。摘要、截图或手工附加材料仍应在分享前检查，不要将整个数据目录直接作为问题附件。

协议覆写文件可能包含主机名、MAC 和 IP。它不必包含密码，也仍可能暴露个人网络信息。格式与保管建议见[协议上报覆写](override.md)。

## 备份与移除

备份前正常退出程序。`configurations.json` 含密码，按敏感文件保管；临时运行信息不是账号备份。安装版与便携版没有自动互相迁移数据的流程。

安装版卸载会询问是否删除账号配置、GUI 设置与日志，默认保留。便携版移除前，撤销已启用的自启和 PATH，再正常退出程序；直接删除便携目录会同时删除其中的账号数据。

更新和卸载操作见[使用指南](guide.md#更新移动与卸载)。
