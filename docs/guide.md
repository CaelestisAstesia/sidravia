# 使用指南

## 连接配置

在「设置 → 连接配置」选择机构，填写账号和密码，并选择网卡。首次配置必须填写密码；已有密码时，密码框会显示占位符，留空即可保留原密码。

点击「保存修改」后，按确认窗口选择保存或保存后连接。已有连接或正在重试时，保存连接配置可能会断开或停止当前连接；需要继续连接时，选择「保存并重新连接」。具体操作以确认窗口的按钮提示为准。

若提示保存结果未知或清理失败，请先按提示核对配置和连接状态，再决定下一步操作。

删除配置会删除保存的账号与密码。只想断开网络认证时，在首页断开即可，无需删除配置。

图形界面目前只管理一份连接配置。需要多配置管理、脚本或协议上报覆写时，请参阅[命令行高级使用](advance.md)。

## 网卡选择

**默认建议保留「自动选择可用网卡」。** Sidravia 的网络自持机制高度依赖自动网卡选择，以便在网络变化时重新选择可用的认证接口，维持或恢复连接。日常使用通常以此为最佳选项。

如果自动选择未选中需要认证的网络，或你明确需要固定认证接口，再手动指定网卡与 IPv4 地址。

手动指定后，程序会遵守该绑定：指定的网卡或 IPv4 地址不可用时，会等待其恢复，不会自动切换到其他网卡或地址。更换网络或地址后，可重新选择当前可用的绑定，或恢复「自动选择可用网卡」。

## 自动连接与开机自启

| 设置 | 用途 |
| --- | --- |
| 启动时自动登录 | 后台启动并取得网络状态后，使用保存的配置自动认证；开启开关不会立即连接 |
| 自动重连 | 断线或发生可恢复错误后自动重试；修改在下次连接时生效 |
| 开机自启 | 当前用户登录 Windows 时启动 Sidravia，可选「启动到托盘」或「仅后台」 |

日常使用图形界面时，建议选择「启动到托盘」。「仅后台」不显示窗口和托盘图标，适合通过命令行管理连接的用户。

开机自启只负责启动程序；如需同时自动认证，还应开启「启动时自动登录」。启用前，请关闭其他认证客户端的开机自启，避免同时运行。

要立即应用修改后的自动重连设置，请断开后重新连接。为便于网络变化后的恢复，建议保留「自动选择可用网卡」。

## 窗口、通知和公告

默认关闭主窗口会隐藏到托盘，连接继续保持。托盘菜单可以重新打开窗口；选择「退出 Sidravia」会断开并退出。在「启动与窗口行为」中，也可以调整启动时隐藏和关闭窗口后的行为。

在「常规」中调整外观模式与通知提醒。通知可选「不提醒」「仅异常」或「全部提醒」，按需控制打扰程度。

首页的学校公告入口用于查看学校原网页。在「公告」中，可选择每次连接成功后、每天首次连接成功后自动显示，或仅手动查看。

主窗口隐藏时，还可选择直接显示公告、发送系统通知后点击查看，或等恢复主窗口时再显示。若通知提醒设为「不提醒」，仍可在首页手动查看公告。

## 连接与诊断

在「设置 → 连接与诊断」查看网卡、IP、认证服务器和连接信息，也可以复制诊断摘要、打开日志目录。反馈问题时，可先复制诊断摘要，检查其中的信息后再分享。

「刷新网络诊断」用于检查认证目标和本机网络情况；「执行有限 IP 探测」会额外发送探测请求。认证成功后仍无法访问网页时，请结合[常见问题](troubleshooting.md)继续排查。

「重启核心」会中断后台及当前连接，再尝试恢复原连接状态，恢复不保证成功。「移除当前会话」用于清理当前会话记录，保留账号配置，无需通过删除配置来清理会话。

日志等级在重启核心后生效。TRACE 会记录原始认证报文，可能包含账号和认证信息，仅在排障需要时开启；排障结束后恢复原日志等级并重启核心。分享日志前，请阅读[日志说明](privacy.md#日志与诊断)。

## 更新、移动与卸载

**预发布（Pre-release）版本之间可能引入不兼容的改动，配置格式、命令参数或使用流程可能发生变化。升级前务必阅读目标版本的发行说明并备份配置，不要假定旧版配置可直接沿用，或新版保存的数据可直接用于回退。**

更新前，先查看新版发行说明，正常退出图形界面和后台，再备份账号配置及需要保留的 GUI 设置。关闭窗口默认只是隐藏到托盘，请从托盘菜单选择「退出 Sidravia」。

- **安装版更新**：使用原 Windows 账户运行新版安装器，按向导更新。需要先卸载旧版时，在删除账号配置、GUI 设置和日志的询问中选择「否」。
- **便携版更新**：将新版完整解压到新目录，保留新版的 `sidravia.portable`。首次启动前，将旧目录 `config` 文件夹中的 `configurations.json` 复制到新目录对应位置；需要保留 GUI 设置时，再复制 `gui-settings.json`。目标已有同名文件时先备份。不要用旧程序、运行记录或机构配置替换新版随包文件。
- **移动便携目录**：先在旧位置撤销开机自启和用户 PATH，退出程序，再移动整个目录；需要时在新位置重新设置。
- **安装版卸载**：退出程序后，从 Windows 应用列表卸载。需要保留账号配置、GUI 设置和日志时，在删除数据的询问中选择「否」。
- **移除便携版**：先撤销开机自启和用户 PATH，退出程序，备份需要保留的配置后再删除目录。目录中的账号配置、GUI 设置和日志也会一起删除。

安装版与便携版不会自动迁移数据。添加或删除 `sidravia.portable` 只会改变数据位置，不会搬迁配置。各类数据和公告网页缓存的位置见[数据与隐私](privacy.md#数据位置)。

若更新或维护时遇到进程占用、自启任务冲突等提示，请先核对实际状态，再按提示处理，相关工具见 [Windows 维护工具](manager.md)。

## 旧版核心包与迁移

使用仅含后台和命令行工具的包时，请参阅[命令行高级使用](advance.md)。命令和参数以所用版本的帮助及文档为准。

如果旧包曾通过 `scripts\install.ps1` 配置用户 PATH 或登录任务，请在移除旧目录前，按原包说明使用原卸载脚本撤销。新版使用内置维护工具，不要将旧脚本复制到新版目录运行。

从旧测试版升级时，请先阅读目标版本发行说明中的升级指南，保留旧包及配置备份，确认新版可用后再清理。
