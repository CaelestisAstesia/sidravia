# 使用指南

## 连接配置

在「设置 → 连接配置」选择机构，填写账号、密码和网卡。已有密码时，密码框会显示占位符；留空就保留原密码。

点击「保存修改」后，可以只保存，也可以保存后连接。正在连接时修改认证信息，会结束旧连接；选择「保存并重新连接」会随后建立新连接。若提示保存结果未知或清理失败，先按提示确认状态。

删除配置会删除保存的账号与密码。只想下线时，在首页断开即可。

GUI 目前只管理一份配置。需要多配置、脚本或协议覆写时，见[高级使用](advance.md)。

## 网卡选择

通常使用自动选择。电脑有多个网络接口时，可以指定认证网络所在的网卡与 IPv4。

指定的网卡或地址不可用时，程序会等待，不会换到另一块网卡。可以重新选择地址，或改回自动选择。

## 自动连接与开机自启

| 设置 | 用途 |
| --- | --- |
| 启动时自动登录 | 后台启动并取得网络状态后，用保存的配置认证；打开开关不会立即连接 |
| 自动重连 | 断线或发生可恢复错误后重试；修改在下次连接时生效 |
| 开机自启 | 当前用户登录 Windows 时启动程序，可选「启动到托盘」或「仅后台」 |

日常使用选「启动到托盘」。如果还想自动认证，需要同时开启自动登录。要立即应用新的重连设置，断开后重新连接。

## 窗口、通知和公告

默认关闭主窗口会隐藏到托盘。托盘菜单可以重新打开窗口，或选择「退出 Sidravia」断开并退出。设置中可以改成关闭窗口就退出，也可以设置启动时隐藏。

外观、通知和公告的显示方式都在设置中调整。首页的学校公告入口打开学校原网页，也可以设为连接成功后自动显示。

## 连接与诊断

在「设置 → 连接与诊断」查看网卡、IP、服务器和连接信息，也可以复制诊断摘要、打开日志目录。

「刷新网络诊断」检查认证目标和本机网络情况；「执行有限 IP 探测」会额外发送探测请求。网页访问仍有问题时，按[常见问题](troubleshooting.md)继续检查。

「重启核心」会中断后台，再尝试恢复原连接状态。「移除当前会话」只清理运行记录，保留账号配置。

日志等级在重启核心后生效。TRACE 含原始认证报文，只在排障时开启，分享前请看[日志说明](privacy.md#日志与诊断)。

## 更新、移动与卸载

更新前退出 GUI 和后台，备份账号配置，并查看新版的升级说明。

- **安装版更新**：运行新安装器。
- **便携版更新**：保留数据目录和 `sidravia.portable`，使用同一发行包中的整套程序文件。
- **移动便携目录**：先撤销自启与 PATH，退出程序，再移动；在新位置重新设置。
- **安装版卸载**：从 Windows 应用列表卸载。询问是否删除账号配置、GUI 设置和日志时，选「否」保留数据。
- **移除便携版**：撤销自启与 PATH，退出后删除目录。目录内的账号数据也会被删除。

安装版与便携版不会自动迁移数据。公告网页缓存另存在用户目录，详见[数据位置](privacy.md#数据位置)。

## 附录：旧版仅含核心的包

只有 ctl 和后台的旧包，可在包目录打开 PowerShell：

```powershell
.\sidraviactl.exe daemon start
.\sidraviactl.exe daemon status
.\sidraviactl.exe profile list
.\sidraviactl.exe auth start --profile jlu --username '<账号>'
```

密码由隐藏提示读取。用返回的 Session ID 查询结果：

```powershell
.\sidraviactl.exe auth status <session-id>
```

停止后台：

```powershell
.\sidraviactl.exe daemon stop
```

`<账号>`、`<session-id>` 替换为实际值，不保留尖括号。

旧包的 `scripts\install.ps1`、`scripts\uninstall.ps1` 管理旧版 PATH 和登录任务；移除旧包前用原卸载脚本撤销。现代包使用内置维护工具。

包内 `GETTING-STARTED.md` 的链接可能没有配套文件，完整说明见[在线文档](https://github.com/CaelestisAstesia/sidravia/tree/main/docs)，请核对版本。
